# 《山》项目说明

项目名称：
《山》——山东大学学生科幻协会二十周年纪念刊

纪念主体：
山东大学学生科幻协会 2006—2026

制作软件：
Adobe InDesign

自动化目标：
使用脚本完成文档基础结构、样式、母版、内容导入和重复性版面工作。
人工负责最终视觉调整、图片裁切、孤行处理、特殊跨页和审美判断。

重要原则：
Codex 只负责实现，不负责重新设计。

未经明确指示，不得：
1. 修改刊名；
2. 修改章节名称；
3. 修改章节顺序；
4. 自行增加科幻装饰；
5. 自行决定页面数量；
6. 自行改变字体、字号、颜色；
7. 自行删除文章；
8. 根据个人判断重新分类文章；
9. 重新设计已确定的视觉体系；
10. 因为内容长度变化而破坏现有样式系统。

---

# 核心视觉概念

关键词：
山、等高线、地层、星图、时间沉积、档案。

禁止将整本刊物设计成常规“科幻风”。
避免：蓝紫星云、宇航员、霓虹赛博朋克、大面积科技HUD、随机发光线条、过度未来主义字体、AI生成宇宙背景。

整体应是一本文学性、档案性较强的高校科幻协会二十周年纪念刊。

---

# 七章结构

山口 / PROLOGUE
火种 / ORIGIN
地层 / STRATA
越岭 / BEYOND THE RIDGE
星图 / CONSTELLATIONS
此刻 / NOW
山外 / BEYOND

章节顺序固定，不得调整。

---

# 章节含义

山口：进入二十年历史的入口，主要放刊首语、编者的话、协会简介与目录。

火种：2006年前后协会创立与早期成员的故事。

地层：2006—2026二十年协会历史、时间线、历届负责人、档案资料。

越岭：协会与其他高校幻协的联系，以及月曜杯、齐鲁科幻联盟等跨校活动。

星图：协会成员创作的科幻作品与个人科幻经历。

此刻：2025—2026年的协会状态、活动、视觉系统、文创与社娘。

山外：历任社长寄语、友协祝福、未来、后记与致谢。

---

# 当前制作原则

主体部分优先制作：火种、地层、越岭、星图、此刻。

山口中的“指导老师刊首语”暂不制作正文，只保留模板。

山外中的历任社长寄语、高校幻协祝福暂不导入正文，只建立模板。

主体完成后将输出阶段PDF，再用于邀请指导老师、历任社长及其他高校幻协撰写内容。

# FRONT NOTE v0.1 — Design intent

Article: 《写在〈山〉前》
Chapter: 山口
Copy status: LOCKED / FINAL

## Purpose
This is the editor's opening note for the 20th-anniversary magazine. It should feel quieter and more spacious than Feature/Interview/Fiction.

## Reusable module
Create a small reusable front-note module for:
- editor's note
- teacher foreword / opening note
- similar front-matter essays

Do not turn this into a general Feature clone.

## Layout direction
- Parent: I-FRONT
- Facing pages supported
- One-column reading experience
- Text block approx. 112–122 mm wide
- Generous outer white space
- Body approx. 9.5–10 pt / 15–16 pt
- Title approx. 22–26 pt, restrained
- Small author/signature field optional, but this sample has none
- SDU red only as tiny accent if needed
- No decorative nebula, star field, illustration, generated image or large graphic
- Use existing Visual System typography / colors
- Keep warm paper background behavior unchanged
- Do not add running header on the opening page if I-FRONT already suppresses it
- Page number may remain according to current front-matter system

## Copy handling
Text must be byte-for-byte / paragraph-for-paragraph equivalent in visible wording.
Do not:
- rewrite
- normalize wording
- add a pull quote
- duplicate “因为山无处不在”
- add section headings
- add editor signature
- change 20年 to 二十年 or vice versa
- alter punctuation

The Liu Cixin quote remains exactly where it appears in the body.
